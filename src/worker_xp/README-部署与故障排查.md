# Windows XP (Win32) 执行端免安装运行包部署与排查指南

本运行包专为 **Windows XP SP3 (32位 x86)** 系统定制，属于自包含免安装绿色包。

---

## 1. 现场使用须知（极简三步）

**目标机无需安装 Python、Node.js、pip 或任何开发编译工具！**

1. **解压目录**：
   将本压缩包完整解压到目标电脑任意目录（支持中文路径或带空格路径，例如 `D:\执行端\` 或 `C:\phoneApp_worker\`）。
2. **首次确认地址**：
   双击 `ConfigureWorker.cmd`。
   程序会显示预设的现场协调服务地址（默认为 `http://192.168.1.183:3001`）。若地址正确直接回车，若协调服务 IP 变动则输入新地址并回车。地址会自动持久化保存到本机的 `data/worker_config.local.json` 中，重启不丢失。
3. **日常启动运行**：
   双击 `StartWorker.cmd`。
   控制台将显示已连接状态、终端分配的独立 ID 以及工作目录，随后持续保持心跳并等待接收任务。

## 2. 运行包文件清单

| 文件名 | 用途说明 |
| --- | --- |
| `worker_xp.exe` | 核心主程序（包含内嵌 Python 3.4 运行时与依赖库） |
| `StartWorker.cmd` | 日常启动脚本（纯 ASCII、CRLF，失败不会闪退） |
| `ConfigureWorker.cmd` | 交互式连接配置工具（调用同一 exe 的 `--configure`） |
| `DiagnoseWorker.cmd` | 只读环境自检与诊断工具（调用同一 exe 的 `--diagnose`） |
| `coordinator.defaults.json` | 现场默认协调端地址预设，不含任何机器身份凭据 |
| `version.json` | 版本号、架构（32-bit x86）、协议版本元数据 |
| `python34.dll` 及依赖 DLL | PyInstaller onedir 运行时必须的动态链接库 |
| `data/` | 运行时自动创建：保存本机独立身份、任务缓存等 |
| `logs/` | 运行时自动创建：运行日志目录 |

## 3. 现场前置软硬件要求

“免安装”指**执行程序本身自包含**，但实际业务中的 Word 文档填充与打印输出仍依赖物理目标机的以下软件：

1. **Office 办公套件**：
   - 必须已安装 **Microsoft Office 2003 / 2007 / 2010** 或 **WPS Office**。
   - 文档生成与打印通过系统标准的 COM 自动化接口（`Word.Application` 或 `Wps.Application`）驱动。
2. **打印机及其驱动程序**：
   - 目标打印机驱动必须在 Windows XP 下安装完毕并处于“就绪”状态。
   - 支持本地 USB 打印机与局域网 Windows 共享打印机。

## 4. 故障排查与自检诊断

若遇到无法启动、未收到任务或打印报错，请按以下步骤诊断：

1. **运行自检诊断**：
   - 双击运行 `DiagnoseWorker.cmd`。
   - 控制台会自动检查并输出：
     - 系统版本与指针位数（必须为 32-bit）
     - 本地数据目录写权限是否正常
     - 本机身份 ID 与配置保存状态（密钥严格脱敏）
     - Word / WPS COM 自动化组件是否可用
     - 当前已检测到的系统打印机列表
     - 与协调服务（183）的网络连通性及 HTTP 响应
2. **常见故障对策**：
   - **连接 OFFLINE / Connection Refused**：
     - 检查目标电脑是否能 ping 通协调服务电脑（如 `192.168.1.183`）。
     - 检查协调服务电脑防火墙是否放行了 3001 端口。
     - 双击 `ConfigureWorker.cmd` 确认输入的 IP 和端口是否正确。
   - **提示 Word/WPS 写入失败**：
     - 运行 `DiagnoseWorker.cmd` 查看 COM 探测结果。若提示不可用，说明目标机缺少 Office 或 WPS，请安装对应办公软件。
   - **打印机切换失败**：
     - 程序具备安全保护：若无法切换到协调端指定的打印机，会立即停止打印并报错，防止错打到默认打印机。请确认目标打印机名称与协调端配置的打印机名称完全一致。
