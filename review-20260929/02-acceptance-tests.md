# 本轮验收用例

以下均为待执行用例。准备 990 证书及本次清单、POA200 模板组和 DPT810 证书；隔离测试数据库、输出目录及打印设备。每项记录实际结果、生成文件、日志与截图，失败不能标通过。

| 编号 | 操作 | 预期及核验方法 |
|---|---|---|
| R01 | 导入原始 990 装箱清单并解析 | 获取真实 7 列、11 条物料，空单元格及一位数字不丢失；位置与 Word 表格逐项核对；不能产生伪造 R14 等坐标。 |
| R02 | 配置名称、规格/型号、数量三列 | 参考值分别显示对应列的真实样例，如主设备/计量证书、DPT-990-Ex/英文、1/1；不得把相邻表头当值。 |
| R03 | 选择标签命中但未指定数据区的表格字段后发布 | 阻止发布并指出缺项；100% 标签命中不等于确认写入范围。空值与未绑定显示不同。 |
| R04 | 新增/删除配置字段；手工选定目标并保存、重开 | 选择完整保留；手机表单与生成写入确实响应此映射。用不在固定默认字段中的字段验证。 |
| R05 | 把数量配置成列、填写逐行不同数字，生成清单 | 所有值写在对应数据行，表头不变；空规格不导致串列，11 行完整。 |
| R06 | 新增两条自定义物料，删除一条普通物料 | 默认 11 条变 12 条，序号连续，名称可自定义；主设备不能删；格式一致，分页无内容丢失。 |
| R07 | 990 清单无传感器行，POA200 有传感器行 | 990 正常生成且不补传感器；POA200 仍保护其真实主设备/传感器行；不全局要求第二行为传感器。 |
| R08 | 同一 modelId 先发布证书，再上传清单草稿 | 手机仍使用之前可用配置，草稿不能执行；管理员看见待配置状态。 |
| R09 | 配好清单并发布同组新版本，刷新手机 | 990 显示证书+清单，表单出现本模板 11 条物料；不出现 POA200 行或传感器型号。 |
| R10 | 修改显示名称、配置兼容旧值 990/DPT-990-EX | 仍指向同一确认过的 modelId；使用正确 templateId；其他型号不能被误合并。 |
| R11 | 新增不同型号及字段配置，不改前后端代码 | 发布后出现新组和字段；任务仅创建该组实际有的文档，生成值对应映射。 |
| R12 | 手机填一半时管理员发布新版 | 提示版本变化并保留输入；不静默改用新版。已受理旧任务按旧模板hash执行。 |
| R13 | 执行端放到另一台电脑，无 samples 和协调端同名目录 | 经模板分发及hash校验正常生成；下载失败明确报错，不套用其他模板。 |
| R14 | 复现旧任务35条件：型号别名及旧 samples 缺失 | 修复后按绑定模板生成正确990证书；若模板确实不可用，显示错误，不提供下载假按钮。此验证在隔离数据中进行。 |
| R15 | 提交990证书+清单，共享序列号EX10260999 | 证书 Inst.SN、清单主设备备注SN一致；两文件均有产物及各自预览；更改一个共享入口同步另一处，冲突请求服务端拒绝。 |
| R16 | 生成失败，点击/查看历史 | 显示具体失败阶段原因；原文件和预览未就绪时按钮不可用；不能只显示FAILED让用户猜。 |
| R17 | 真实Word转换为预览 | PDF/所有页图片与原文件逐页比对：标题、11条物料、页眉页脚、logo、分页、数据一致；无固定SVG重画替代。 |
| R18 | 缺少转换组件、转换超时或文件损坏 | 显示转换失败原因，不能PREVIEW_READY/SUCCESS；原件存在时下载仍可用；无无限加载。 |
| R19 | 修复转换环境后重试预览 | 原Word hash、名称不变；只重新转换，不生成另一任务或触发打印。 |
| R20 | 预览成功后刷新、退出重开、重启协调服务 | 同条历史仍能下载原件并查看全部页；路径不能依赖一次性内存对象。 |
| R21 | 中文/括号文件名，分别用doc与docx模板 | 实际文件格式与模板一致；上传、下载、命名无乱码；解析、生成、预览都成功，不能仅改扩展名。 |
| R22 | 对照POA200/DPT810回归 | POA传感器下拉仍由自身配置决定；DPT810无清单时不出现清单；Customer保持模板；温湿度及测量表逐行正确。 |
| R23 | 失败后跨日确认重试，管理员已发布新模板 | 既定命名日期不变，不静默更换模板；旧模板不可用明确提示，不私自套新版。 |
| R24 | 删除或移动历史实际产物（仅隔离环境） | 原件/预览不存在时给出“文件缺失”，其他产物状态不误报；不靠仅有数据库记录启用无效链接。 |

特别检查：对所有生成样本比较源模板生成前后 SHA256，原模板不能被修改。任务35的既有失败记录不能被当成预览转换失败用例的执行证据；两类错误要独立测试。
