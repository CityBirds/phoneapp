## 2. 协议参数补充与复核问题（A、B、C）修正验证

### 补充协议参数确认
1. **通信端口**：W610 与协调服务连通方式为 **TCP SERVER**，默认端口由 `80` 调整为 **`8899`**。
2. **最大帧长度**：YKBUS 流解析器将单帧上限由 4096 字节放宽至 **`65536`** 字节，防止长帧被误拦截。

### 问题 A：生产请求仍可触发模拟成功（违反规范 COMM-15）
- **原因与修复**：
  1. `src/backend/server.js` 的 `POST /api/w610/tasks` 接口中，主动剔除了客户端 `payload` 中的所有模拟标识（`isMock`, `enableMock`, `isTestMock`, `mockDeviceInfo`, `mockFailStage`, `mock`），且 `w610Device` 强制从数据库中查询绑定，不接受客户端传入。
  2. `src/worker/worker.js` 与 `src/worker_xp/worker_xp.py` 限制模拟逻辑必须由**进程级显式测试开关**触发（环境变量 `W610_TEST_MOCK=1` 或构造函数显式标志 `enableTestMock: true`）。payload 包含 `isMock` 字段时不再开启模拟。
  3. 设备地址为 `127.0.0.1` 时，当测试模拟开关未开启，照常进行真实 TCP 通信。
  4. `packDeviceInfo` / `pack_device_info` 函数在未传入合法 248 字节原始块 `existingBuf` 时一律抛出错误，禁止从零重建。

### 问题 B：超时租约恢复会导致重复写设备（违反规范第 5 节第 5、9 步，COMM-12/18）
- **原因与修复**：
  1. `src/backend/server.js` 的 `/api/worker/w610-tasks/pending` 接口中，对超过 60 秒未更新的 `PROCESSING` 任务区分动作类型：只读任务（`probe`, `read_device`）恢复为 `PENDING`，而写设备任务（`write_and_save`）直接标记为 `RESULT_UNKNOWN` 并记录明确原因，防止重新下发产生第二次写操作。
  2. 增加了 `/api/worker/w610-tasks/:taskId/renew-lease` 租约续期接口，执行端在长时间读写或网络等待阶段可定期续期。
  3. 任务结果回传接口 `POST /api/worker/w610-tasks/:taskId/result` 保证幂等，对已定案的任务重复回报不回退状态。

### 问题 C：编造的 W610 HTTP 接口仍然保留（违反规范 P1 第 4 条）
- **原因与修复**：
  1. 删除了 `src/worker/poa200_protocol.js` 与 `src/worker_xp/poa200_protocol_xp.py` 中的 `/api/v1/transfer` HTTP 桥接实现。
  2. 仅保留当前确认的 TCP 透传适配器（端口 8899），配置为非 TCP 传输方式时返回 `UNSUPPORTED_TRANSPORT` 错误，并附带注释：“TCP 透传方式与端口待 W610 固件确认，未经实机验证”。

1. `src/backend/server.js`：清洗 `POST /api/w610/tasks` 模拟字段，防止客户端注入 mock，绑定数据库 `w610Device`；修改 pending 租约恢复逻辑（`write_and_save` 租约超时转 `RESULT_UNKNOWN`）；新增租约续期接口 `/api/worker/w610-tasks/:taskId/renew-lease`；保证结果回报幂等；更新默认通信端口为 8899。
2. `src/backend/db.js`：更新数据库结构定义中 `w610_devices.port` 默认值为 `8899`。
3. `src/worker/poa200_protocol.js`：严格校验 248 字节原块 `existingBuf`；移除 `/api/v1/transfer` HTTP 桥接适配器；非 TCP 传输直接返回 `UNSUPPORTED_TRANSPORT`；更新默认 TCP 端口为 8899；将流拆包单帧长度上限提升为 65536 字节。
4. `src/worker_xp/poa200_protocol_xp.py`：Python XP 端严格校验 248 字节原块；移除 HTTP 桥接传输；非 TCP 传输返回 `UNSUPPORTED_TRANSPORT`；更新默认端口为 8899。
5. `src/worker/worker.js`：支持进程级测试开关 `enableTestMock`；长操作租约续期；发送写命令超时或设备无响应时回报 `RESULT_UNKNOWN` 而非挂起或重试；更新探测逻辑默认端口为 8899。
6. `src/worker_xp/worker_xp.py`：Python XP 端对齐进程级测试开关 `enable_test_mock` 与租约续期/`RESULT_UNKNOWN` 汇报逻辑；更新探测逻辑默认端口为 8899。
